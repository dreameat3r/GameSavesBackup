# GameSavesBackup
A simple AvaloniaUI application for copying save files (and more). Created either for games without cloud saves (so as not to do it manually each time), or for some experiments with saves.

---

## Features:
Create, edit and delete presets
Backup in one click. Swap paths in one click.

## Installation

### Windows:
1. Download the latest release.
2. Unzip `.zip`
3. Launch `GameSavesBackup.exe`

### Linux:
Linux release coming soon. (Or you can build it by yourself)

## Note:
The release already has an example preset. You can change or delete it.
When selecting a folder, remember that the application does not create a folder with the same name, but only copies files inside the folder. Therefore, create the final folder manually (you can add it directly to the final path textbox and it will be created automatically during backup)
